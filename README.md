# AI-Button-Remap-for-Xiaomi-Mi-9
A KernelSU module to change the AI button function.
###
##
#

Here's the list of available functions:  
Camera (CAMERA)
Screenshot (SYSRQ)
Google Search (SEARCH)
Google Assistant (VOICE_ASSIST)
Call (CALL)
Contacts (CONTACTS)
Music Player (MUSIC)
Mute/Unmute Media Volume (VOLUME_MUTE)
Play/Pause Media (MEDIA_PLAY_PAUSE)
Next Media (MEDIA_NEXT)
Recent Apps (APP_SWITCH)
Open/Close Quick Settings (QPANEL_ON_OFF)
Internet Browser (EXPLORER)
Calendar (CALENDAR)
Calculator (CALCULATOR)
Power button (POWER)
No Function (NOF)

If you want to use it for Google Assistant, I recommend setting it to Play/Pause Media (MEDIA_PLAY_PAUSE).
A single press will play or pause media, while a long press will open Google Assistant.
This prevents accidental interruptions while playing games.
If you press the button by mistake, it will only pause or play background media, and if nothing is playing, nothing will happen.
